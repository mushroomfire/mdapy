    References¶

    The papers that MDAPY follows or that its pages cite, each listed once; the pages link here. A feature built on published work ends its page with the papers to cite when it is used.

    Citing MDAPY¶

    If MDAPY contributes to a publication, please cite Wu and Shao (2023):

    @article{mdapy2023,
  title   = {mdapy: A flexible and efficient analysis software for
             molecular dynamics simulations},
  author  = {Yong-Chao Wu and Jian-Li Shao},
  journal = {Computer Physics Communications},
  volume  = {290},
  pages   = {108764},
  year    = {2023},
  doi     = {10.1016/j.cpc.2023.108764},
}
