    Energy minimization¶

    minimize ¶

    minimize(system, calculator, *, max_force=0.001, max_steps=1000, max_step=0.1, timestep=0.001, cell=None, pressure=0.0, max_stress=0.01, save_every=None, callback=None, log=None, log_every=10, comm=None)

    Minimizes the energy over the positions, and optionally the box, with FIRE 2.0.

    Parameters:

    Name Type Description Default
    system System

    The starting configuration, with a mass or an element column; a movable column, (N, 3) bool, keeps each atom still along the directions where it is False.

    		 required
    calculator Calculator

    Computes energies and forces, and the virial when the box relaxes.

    		 required
    max_force float64

    Convergence: the largest force on any atom, in eV/Å. Default 1e-3.

    		 0.001
    max_steps int32

    Largest number of steps. Default 1000.

    		 1000
    max_step float64

    Largest displacement of an atom along x, y or z in one step, in Å. Default 0.1.

    		 0.1
    timestep float64

    First time step of the dynamics, in ps. Default 0.001.

    		 0.001
    cell (None, isotropic, axes, full)

    How the box may change along its periodic directions: not at all (default), by one scale factor, by a scale factor along each Cartesian axis, or by any strain without rotation.

    		 None
    pressure float64

    External hydrostatic pressure in GPa when the box relaxes; the enthalpy is minimized. Default 0.

    		 0.0
    max_stress float64

    Convergence when the box relaxes: the largest deviation of a relaxed stress component from the target, in GPa. Default 0.01.

    		 0.01
    save_every int32

    Keeps the configuration every this many steps, with the first and the last, in frames of the result. Default None, keeping none.

    		 None
    callback callable

    Called after every step as callback(step, system, energy, max_force); returning True stops the minimization.

    		 None
    log (str, PathLike or stream)

    Writes the minimization to this file, which it overwrites, or to this stream, such as sys.stdout: a heading, the energy, the largest force and, when the box relaxes, the largest deviation of the stress from its target every log_every steps and at the last, with the seconds since the start, and how it ended. Lines that are not rows of numbers start with #, so that numpy.loadtxt reads the rows. Default None, writing none.

    		 None
    log_every int32

    Writes a row to the log every this many steps. Default 10.

    		 10
    comm mpi4py communicator

    The processes that share the forces of this minimization, each holding the same system; MPI.COMM_SELF minimizes on each process alone. Default None: every process that MPI started. A LAMMPS calculator computes on its own processes.

    		 None

    Returns:

    Type Description
    MinimizeResult

    The last configuration and whether it converged.

    Raises:

    Type Description
    InvalidParameter

    For invalid options, a calculator without the properties needed, a log that cannot be written, comm that is not a communicator, or processes of one minimization that hold different systems or options.
    MissingProperty

    If the system has neither masses nor elements.

    MinimizeResult dataclass ¶

    MinimizeResult(system, converged, steps, energy, max_force, stress=None, frames=None)

    Bases: Result

    The outcome of minimize.

    Attributes:

    Name Type Description
    system System

    The last configuration, with forces and atomic_energies columns and energy, and with a virial virial and stress, in info.
    converged bool

    Whether every force fell below max_force and, when the box relaxed, every relaxed stress component came within max_stress of the target.
    steps int32

    Number of steps taken.
    energy float64

    Energy of the last configuration in eV.
    max_force float64

    Largest force of the last configuration in eV/Å.
    stress ndarray or None

    (3, 3) float64 stress of the last configuration in GPa, positive under tension; None when the calculator computes no virial.
    frames tuple of System or None

    With save_every, the configurations at step 0, every save_every steps and the last step, with the columns and information of system and the step number as timestep in info; None otherwise.

    Minimum energy paths¶

    neb ¶

    neb(initial, final, calculator, *, images=5, climb=True, spring=1.0, interpolation='linear', max_force=0.01, max_steps=1000, max_step=0.1, timestep=0.001, callback=None, log=None, log_every=10, comm=None)

    Finds the minimum energy path between two states with the nudged elastic band, its highest image climbing to the saddle point.

    Parameters:

    Name Type Description Default
    initial System

    The two states, each a minimum of the energy (relaxed with minimize), with the same atoms in the same order and the same box; a mass or an element column; a movable column of the initial state, (N, 3) bool, keeps each atom still along the directions where it is False.

    		 required
    final System

    The two states, each a minimum of the energy (relaxed with minimize), with the same atoms in the same order and the same box; a mass or an element column; a movable column of the initial state, (N, 3) bool, keeps each atom still along the directions where it is False.

    		 required
    calculator Calculator or sequence of Calculator

    Computes energies and forces; or one for each image between the states, which then compute at the same time, each in a thread of its own: for calculators that each run on their own, such as VASP in directories of their own.

    		 required
    images int32 or sequence of System

    Number of images between the states, interpolated by interpolation, or the images themselves to start from. Default 5.

    		 5
    climb bool

    Whether the image of highest energy climbs to the saddle point. Default True.

    		 True
    spring float64

    Constant of the springs between the images along the band, in eV/Å². Default 1.0.

    		 1.0
    interpolation (linear, idpp)

    How the images start: on the straight line between the states, each atom by its shortest periodic displacement, or relaxed from it on the image dependent pair potential, which keeps the distances between atoms near those of the states. Default "linear".

    		 "linear"
    max_force float64

    Convergence: the largest force of the band on an atom of an image, in eV/Å. Default 0.01.

    		 0.01
    max_steps int32

    Largest number of steps. Default 1000.

    		 1000
    max_step float64

    Largest displacement of an atom along x, y or z in one step, in Å. Default 0.1.

    		 0.1
    timestep float64

    First time step of the FIRE 2.0 dynamics of the band, in ps. Default 0.001.

    		 0.001
    callback callable

    Called after every step as callback(step, images, energies, max_force), with the band as a tuple of System; returning True stops it.

    		 None
    log (str, PathLike or stream)

    Writes the band's relaxation to this file, which it overwrites, or to this stream: a heading, the largest force, the barrier and the image of highest energy every log_every steps and at the last, and how it ended. Lines that are not rows of numbers start with #. Default None, writing none.

    		 None
    log_every int32

    Writes a row to the log every this many steps. Default 10.

    		 10
    comm mpi4py communicator

    The processes that share the images of this band, each computing its own; MPI.COMM_SELF runs the band on each process alone, as with a LAMMPS calculator on several processes, which computes every image on all of them. Default None: every process that MPI started.

    		 None

    Returns:

    Type Description
    NEBResult

    The band, its energies and the barrier.

    Raises:

    Type Description
    InvalidParameter

    For invalid options, states that differ in their atoms or box, images that do not fit them, calculators that do not compute energies and forces, comm that is not a communicator, processes of one band that hold different states or options, or a LAMMPS calculator on several processes while the images are shared.
    MissingProperty

    If the system has neither masses nor elements.
    CalculationFailed

    If an energy or a force is not finite.

    NEBResult dataclass ¶

    NEBResult(images, energies, distances, barrier, highest, converged, steps, max_force)

    Bases: Result

    The outcome of neb.

    Attributes:

    Name Type Description
    images tuple of System

    The band, the two states first and last, each with a forces column and energy in info: the forces of the calculator, not those of the band.
    energies ndarray

    (M,) float64 energy of each image in eV.
    distances ndarray

    (M,) float64 distance of each image from the first along the band, in Å: the sums of the lengths of the steps between images, over all atoms.
    barrier float64

    Highest energy of the band less that of the first state, in eV.
    highest int32

    Index of the image of highest energy; with climb, it is on the saddle point.
    converged bool

    Whether no force of the band on an atom of the images between the states exceeds max_force.
    steps int32

    Number of steps taken.
    max_force float64

    Largest force of the band on an atom of the images between the states, in eV/Å.

    Parameters:

    Molecular dynamics¶

    MolecularDynamics ¶

    MolecularDynamics(system, potential, *, timestep=0.001, log=None, beads=1, comm=None)

    Molecular dynamics of a system: in LAMMPS with a LAMMPS calculator, in MDAPY itself with any other calculator.

    Parameters:

    Name Type Description Default
    system System

    The atoms, with an element column (or, without LAMMPS, a mass column); their velocities, if the system has them, in Å/ps; a movable column, (N, 3) bool, keeps atoms still along the directions where it is False (not with LAMMPS).

    		 required
    potential Calculator

    The interaction: a LAMMPS calculator, run in LAMMPS, or any other calculator of MDAPY, run in MDAPY, which needs its energies, forces and, for a barostat or the pressure, its virials.

    		 required
    timestep float64

    Time step in ps. Default 0.001.

    		 0.001
    log (str, PathLike or stream)

    Writes the runs to this file, which it overwrites, or to this stream, such as sys.stdout: a heading, the settings of each run, the thermodynamic state every thermo steps with the seconds since the run began, and the speed of each run. Lines that are not rows of numbers start with #, so that numpy.loadtxt reads the rows of every run as one table. Under MPI the main process writes. Default None, writing none.

    		 None
    beads int32

    The beads of the ring polymer of each atom, for path-integral molecular dynamics of the quantum nuclei; 1, classical. Default 1.

    		 1
    comm mpi4py communicator

    The processes that run this dynamics together, split among them, each holding the same system and taking the same runs; with a LAMMPS calculator, the processes of LAMMPS. MPI.COMM_SELF runs it on each process alone, for a simulation of its own on each. Default None: every process that MPI started, as mpirun or srun start them; with a LAMMPS calculator, its own.

    		 None

    Attributes:

    Name Type Description
    timestep float64

    Time step in ps.

    Raises:

    Type Description
    InvalidParameter

    If the potential is not a calculator, the time step is not positive, an element has no atom type, LAMMPS rejects the commands, the log cannot be written, comm is not a communicator, or the processes of comm hold different systems.
    MissingProperty

    If the system has no element column (with LAMMPS), or neither a mass nor an element column.
    ImportError

    If the LAMMPS Python module is not installed, with a LAMMPS calculator.

    run ¶

    run(steps, *, ensemble='nve', temperature=None, pressure=None, barostat='iso', thermostat='nose-hoover', thermostat_damping=None, barostat_damping=None, seed=None, keep_momentum=False, hugoniot=None, shock_velocity=None, msst=None, thermo=100, save_every=None, controls=None, progress=None, cancel=None, restart=None, restart_every=None)

    Runs molecular dynamics.

    Parameters:

    Name Type Description Default
    steps int32

    Number of steps.

    		 required
    ensemble (nve, nvt, npt, nph, nphug, msst)

    Constant energy, or a thermostat, and barostat, or a barostat alone, or a barostat and a thermostat that keeps the atoms on the Hugoniot of a reference state, as LAMMPS's fix nphug, or the box compressed along an axis as by a steady shock of shock_velocity, as fix msst. Default "nve".

    		 "nve"
    temperature float64 or (float64, float64)

    Temperature in K of the thermostat, or its values at the start and the end of the run; needed for "nvt" and "npt".

    		 None
    pressure float64 or (float64, float64)

    Pressure in GPa of the barostat, or its values at the start and the end; needed for "npt", "nph" and "nphug", one value for "nphug".

    		 None
    barostat (iso, aniso, tri, xy, x, y, z)

    The box changes alike in every direction, along each axis, in any way, alike along its first two vectors with the third kept, or along one axis alone, the others kept. A sheet, periodic along its first two vectors only, changes in its plane only: alike along them for "iso" and "xy", along each for "aniso", and in any way in the plane for "tri". Along one axis the box needs its first vector along x and its second in the xy plane, periodic along that axis. "nphug" takes "iso", "aniso" and "tri" under the same pressure along every axis, or one axis for a uniaxial compression; "msst" the axis of the shock. Default "iso".

    		 "iso"
    thermostat (nose - hoover, langevin)

    A chain of Nosé-Hoover thermostats, or Langevin dynamics; with beads the "langevin" thermostat is PILE_L. Default "nose-hoover".

    		 "nose-hoover"
    thermostat_damping float64

    Damping time of the thermostat in ps, positive. With beads it is that of the centroids, the other modes damped critically, and math.inf leaves the centroids free, thermostatted ring-polymer molecular dynamics (TRPMD). Default 100 time steps.

    		 None
    barostat_damping float64

    Damping time of the barostat in ps. Default 1000 time steps.

    		 None
    seed int32

    Seed of the random forces of Langevin dynamics, positive; unpredictable when None.

    		 None
    keep_momentum bool

    With Langevin dynamics, random forces that sum to zero, which keep the total momentum, as LAMMPS's fix langevin zero yes; with no atoms held or moved. Default False.

    		 False
    hugoniot (float64, float64, float64)

    For "nphug" and "msst", the reference state of the Hugoniot: its total energy in eV, volume in Å³ and pressure in GPa, along the axis of a barostat along one axis or of the shock. Default None, the state at the start of the run.

    		 None
    shock_velocity float64

    For "msst", the velocity of the shock in Å/ps, not negative.

    		 None
    msst dict

    For "msst", its settings: "q", the mass of the box in amu²/Å⁴ (default 10), "mu", an artificial viscosity in amu/(Å ps) (default 0), and "tscale", the share of the kinetic energy given to the compression at the start (default 0.01), as in fix msst.

    		 None
    thermo int32

    Records the thermodynamic state every this many steps, and at the start and the end. Default 100.

    		 100
    save_every int32

    Keeps the atoms every this many steps, in frames. Default None, keeping none.

    		 None
    controls sequence of controls

    Hold, Move, AddForce, Langevin, Deform or AdaptiveTimestep: what is done to groups of atoms, the box or the time step during the run: atoms held, moved at a velocity, pushed, or kept at a temperature, the box deformed at constant rates, the time step set by the fastest atom. Held and moved atoms take no part in the thermostat, and the temperature counts the directions that move freely; held or moved atoms not with a barostat or a deformation, baths not with the thermostat of "nvt" or "npt". Default none.

    		 None
    progress callable

    Called as progress(done, total) with the steps run.

    		 None
    cancel CancelToken

    Stops the run, which raises mdapy.errors.Cancelled.
