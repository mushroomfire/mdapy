    Pictures¶

    render ¶

    render(system, path=None, *, atoms=None, color=None, colormap='viridis', value_range=None, representation='spheres', radius=None, bonds=None, bond_radius=None, box=True, box_radius=None, box_color='black', polyhedra=None, polyhedra_alpha=0.6, polyhedra_color='atom', polyhedra_edges=None, mesh=None, mesh_color='#8fb0d8', mesh_alpha=1.0, dislocations=None, dislocation_radius=0.5, burgers_vectors=False, burgers_scale=3.0, burgers_radius=0.3, burgers_color=(0.7, 0.7, 0.7), vectors=None, vector_scale=1.0, vector_radius=0.5, vector_color=(1.0, 1.0, 0.0), vector_alignment='base', lines=None, line_radius=0.1, line_color=(0.6, 0.6, 0.6), wrap_lines=False, legend=False, **options)

    A picture of a system: its atoms, optionally bonds, the box, Voronoi cells and a surface.

    Parameters:

    Name Type Description Default
    system System

    The atoms.

    		 required
    path str or path - like

    A PNG file to write the picture to.

    		 None
    atoms array_like

    A boolean mask or indices of the atoms shown. Default all.

    		 None
    color optional

    The colors of the atoms, see atom_colors. Default those of the elements.

    		 None
    colormap str

    The colormap of values. Default viridis.

    		 'viridis'
    value_range sequence of float64

    The values at the two ends of the colormap.

    		 None
    representation str

    How atoms and bonds are drawn, one of REPRESENTATIONS: spheres, ball_and_stick, space_filling or licorice. It sets the defaults of radius, bonds and bond_radius. Default spheres.

    		 'spheres'
    radius (float32, array_like or str)

    Radius of the atoms in Å, one or (N,) each, or the radii of the elements: "display", "covalent" or "vdw". Default the radius column of the system where it has one, else that of the representation.

    		 None
    bonds (float64, NeighborList, covalent or topology)

    Bonds between the atoms closer than this cutoff in Å, the pairs of a neighbor list, covalent bonds (see covalent_bonds), or the bonds of the topology of the system, such as those of a LAMMPS data file or of mdapy.transform.create_bonds. Default that of the representation.

    		 None
    bond_radius float32

    Radius of the bonds in Å. Default that of the representation.

    		 None
    box bool

    Draw the edges of the box. Default True.

    		 True
    box_radius float32

    Radius of the edges in Å. Default a tenth of the median atom radius.

    		 None
    box_color color

    Color of the edges. Default black.

    		 'black'
    polyhedra VoronoiPolyhedra

    Voronoi cells to draw for the atoms shown.

    		 None
    polyhedra_alpha float32

    Opacity of the cells. Default 0.6.

    		 0.6
    polyhedra_color (atom, edges)

    Color the faces as their atoms, or by their number of edges. Default atom.

    		 "atom"
    polyhedra_edges float32

    Radius in Å of the edges of the cells; 0 draws none. Default a twentieth of the median atom radius.

    		 None
    mesh TriangleMesh

    A surface to draw, such as that of mdapy.analysis.SurfaceMesh. Triangles across a periodic boundary are cut there, the part outside moved in through the opposite face.

    		 None
    mesh_color optional

    One color for the surface, or (F, 3) colors of its triangles. Default light blue.

    		 '#8fb0d8'
    mesh_alpha float32

    Opacity of the surface. Default 1.

    		 1.0
    dislocations DislocationResult

    Dislocation lines to draw, such as those of mdapy.analysis.DislocationAnalysis: tubes in the color of the family of their Burgers vector, cut at the periodic boundaries, the parts outside moved in through the opposite faces.

    		 None
    dislocation_radius float32

    Radius of the tubes in Å. Default 0.5.

    		 0.5
    burgers_vectors bool

    Also draw the Burgers vector of each line: an arrow from the middle of the line along the vector in space. Default False.

    		 False
    burgers_scale float32

    Length of the arrows in units of the Burgers vectors. Default 3.

    		 3.0
    burgers_radius float32

    Radius of the shafts of the arrows in Å. Default 0.3.

    		 0.3
    burgers_color optional

    One color for the arrows, or "family" for the color of each line. Default light gray.

    		 (0.7, 0.7, 0.7)
    vectors str or array_like

    A column of three components, such as displacement, velocities or forces, or (N, 3) vectors: an arrow for each atom shown.

    		 None
    vector_scale float32

    Length of the arrows in units of the vectors; negative reverses them. Default 1.

    		 1.0
    vector_radius float32

    Radius of the shafts of the arrows in Å. Default 0.5.

    		 0.5
    vector_color optional

    One color for the arrows, or "atom" for the color of each atom. Default yellow.

    		 (1.0, 1.0, 0.0)
    vector_alignment (base, center, head)

    The point of the arrow at its atom: its tail, its middle or its tip. Default base.

    		 "base"
    lines array_like or sequence of array_like

    Polylines to draw, such as the paths of mdapy.analysis.trajectory_lines: (M, T, 3) points, or (T, 3) points of each line.

    		 None
    line_radius float32

    Radius of the lines in Å. Default 0.1.

    		 0.1
    line_color optional

    One color for the lines, or a color for each line. Default gray.

    		 (0.6, 0.6, 0.6)
    wrap_lines bool

    Cut the lines at the periodic faces of the box and move the parts outside in through the opposite faces (True), or draw them as they are (False, default).

    		 False
    legend (bool, str or mapping)

    A legend in a column of its own at the left of the picture, the scene framed in the rest, which needs matplotlib. True gives the names of the structures or elements of the atoms shown with their colors, or a bar with the values and the colormap of a column or of (N,) values. A string does the same with this title, as for values that have no name. A mapping gives its own names and colors. Default none.

    		 False
    **options Any

    The options of Scene.render, such as width, height, view, style, zoom, perspective and background.

    		 {}

    Returns:

    Type Description
    ndarray

    (height, width, 4) uint8 RGBA picture.
