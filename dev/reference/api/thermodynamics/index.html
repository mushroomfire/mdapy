    Thermodynamics¶

    Free energy¶

    free_energy ¶

    free_energy(system, potential, temperatures, *, phase='solid', pressure=0.0, timestep=0.001, equilibration=10.0, switching=50.0, scan=100.0, repeats=1, mixing=False, melt_temperature=None, barostat=None, seed=1, progress=None, cancel=None)

    The free energy of a solid or a liquid, per atom, from molecular dynamics in LAMMPS, with classical atoms.

    Parameters:

    Name Type Description Default
    system System

    The atoms, with an element column, in a box periodic in every direction: for a solid at their places in the crystal (relax them first), for a liquid anywhere, as it is melted first.

    		 required
    potential LAMMPS

    The interaction. A liquid needs one pair style, not a hybrid.

    		 required
    temperatures float64 or array_like

    Temperatures in K, positive. The free energy is calculated at the first, and followed from there to the others, which must lie on one side of it, in order.

    		 required
    phase (solid, liquid)

    The phase. Default "solid".

    		 "solid"
    pressure float64 or None

    Pressure in GPa for the Gibbs energy; None for the Helmholtz energy in the box of system. Default 0.

    		 0.0
    timestep float64

    Time step in ps. Default 0.001.

    		 0.001
    equilibration float64

    Time in ps of each equilibration. Default 10.

    		 10.0
    switching float64

    Time in ps of each switching between two interactions. Default 50.

    		 50.0
    scan float64

    Time in ps of each run between the first and the last temperature. Default 100.

    		 100.0
    repeats int32

    Independent calculations at the first temperature. Default 1.

    		 1
    mixing bool

    Add the ideal entropy of mixing of a random solid solution, whose atoms do not exchange places in the dynamics. A liquid has it by itself. Default False.

    		 False
    melt_temperature float64

    Temperature in K at which a liquid is melted. Default twice the first temperature.

    		 None
    barostat (iso, aniso, tri)

    How the box of a solid changes, as in MolecularDynamics.run. Default "aniso", and "iso" for a liquid.

    		 "iso"
    seed int32

    Seed of the random numbers, positive. Default 1.

    		 1
    progress callable

    Called as progress(done, total) with the steps run.

    		 None
    cancel CancelToken

    Stops the calculation, which raises mdapy.errors.Cancelled.

    		 None

    Returns:

    Type Description
    FreeEnergyResult

    The free energy, enthalpy, entropy and volume per atom at each temperature. A phase that changes on the way, as a crystal melts when it is too hot, leaves out the temperatures from there on, with a warning.

    Raises:

    Type Description
    InvalidParameter

    For invalid options, a box not periodic in every direction, a hybrid pair style for a liquid, a liquid that does not move as one, a phase that changes in every scan, or if LAMMPS fails.
    MissingProperty

    If the system has no element column.
    Cancelled

    If cancelled.

    FreeEnergyResult dataclass ¶

    FreeEnergyResult(temperatures, pressure, free_energy, enthalpy, entropy, volume, phase, error, dissipation, system)

    Bases: Result

    The free energy of a phase, per atom.

    Attributes:

    Name Type Description
    temperatures ndarray

    (T,) float64, the temperatures in K.
    pressure float64 or None

    The pressure in GPa, None at constant volume.
    free_energy ndarray

    (T,) float64, the Gibbs energy in eV, or at constant volume the Helmholtz energy.
    enthalpy ndarray

    (T,) float64, the enthalpy in eV, or at constant volume the energy.
    entropy ndarray

    (T,) float64, the entropy in eV/K.
    volume ndarray

    (T,) float64, the volume in Å³.
    phase str

    "solid" or "liquid".
    error float64 or None

    The standard error in eV of the free energy at the first temperature, from the repeats; None for one repeat.
    dissipation ndarray

    (T,) float64 half the difference in eV of the work there and back: near zero when the switching and the scan are slow enough and the phase stays as it is.
    system System

    The atoms in the box of the first temperature.

    Melting point¶

    melting_point ¶

    melting_point(crystal, potential, temperature, *, pressure=0.0, num_atoms=16000, repeat=None, timestep=0.001, equilibration=10.0, coexistence=500.0, tolerance=3.0, max_runs=8, barostat_damping=None, seed=1, progress=None, cancel=None)

    The melting point of a crystal, from a first guess, by the two-phase method: a solid and a liquid share a box at constant enthalpy, where they reach their common temperature while the interface between them moves. A run in which one phase takes over gives a new guess, until the two last.

    Parameters:

    Name Type Description Default
    crystal System

    The crystal, relaxed, with an element column, in a box periodic in every direction; the interface between the phases is across its third vector.

    		 required
    potential LAMMPS

    The interaction.

    		 required
    temperature float64

    The first guess in K, positive.

    		 required
    pressure float64

    Pressure in GPa. Default 0.

    		 0.0
    num_atoms int32

    About how many atoms the box holds, three times as long along its third vector as along the others. Default 16000; fewer for a slow potential, at the price of a larger spread between runs.

    		 16000
    repeat array_like

    (3,) int32 repeats of crystal along its vectors, instead of num_atoms; the third is made even.

    		 None
    timestep float64

    Time step in ps. Default 0.001.

    		 0.001
    equilibration float64

    Time in ps of each stage before the two phases meet. Default 10.

    		 10.0
    coexistence float64

    Time in ps of each stretch of the two phases, of which a run has two or more, up to five, while the temperature drifts. Default 500; a larger box needs longer, as heat takes longer to cross it.

    		 500.0
    tolerance float64

    How much in K the temperature may still drift, from the third quarter of a stretch of coexistence to the last and from the stretch before to this one, for it to be the answer; twice its statistical error, if that is larger. Default 3.

    		 3.0
    max_runs int32

    Largest number of runs. Default 8.

    		 8
    barostat_damping float64

    Damping time of the barostat in ps, as in MolecularDynamics.run. Default 1000 time steps.

    		 None
    seed int32

    Seed of the random numbers, positive. Default 1.

    		 1
    progress callable

    Called as progress(done, total) with the steps run, of a total that takes every run to be the last.

    		 None
    cancel CancelToken

    Stops the calculation, which raises mdapy.errors.Cancelled.

    		 None

    Returns:

    Type Description
    MeltingPointResult

    The melting point, its error, the runs, and the temperature, pressure and fraction of solid atoms along the last run.

    Raises:

    Type Description
    InvalidParameter

    For invalid options, a box not periodic in every direction, if half of the crystal does not melt, if no run ends with two phases within max_runs, or if LAMMPS fails.
    MissingProperty

    If the system has no element column.
    Cancelled

    If cancelled.

    Stacking faults at finite temperature¶

    stacking_fault_free_energy ¶

    stacking_fault_free_energy(crystal, potential, direction, temperatures, *, height=None, axis=2, pressure=0.0, timestep=0.001, equilibration=10.0, switching=50.0, repeats=4, max_force=0.0001, max_steps=10000, seed=1, progress=None, cancel=None)

    The free energy of a stacking fault at each temperature: the difference of the free energies of the crystal with and without it, in one box of the size the crystal has at that temperature and pressure.

    Parameters:

    Name Type Description Default
    crystal System

    The crystal, relaxed, with an element column, periodic in every direction, with the plane of the fault normal to the Cartesian axis of axis, such as fcc with z along [111]. The wider the plane the smaller the error, as the error of the free energy of the atoms grows more slowly than the area does.

    		 required
    potential LAMMPS

    The interaction.

    		 required
    direction array_like

    (3,) float64, the slip vector in Å, in the plane, such as a/6 [11-2].

    		 required
    temperatures float64 or array_like

    Temperatures in K, positive.

    		 required
    height float64

    The fault, at this fractional coordinate along the box vector of axis. Default between the two layers of atoms nearest the middle of the box.

    		 None
    axis int32 or str

    The Cartesian axis normal to the fault. Default z.

    		 2
    pressure float64

    Pressure in GPa. Default 0.

    		 0.0
    timestep float64

    Time step in ps. Default 0.001.

    		 0.001
    equilibration float64

    Time in ps of each equilibration. Default 10.

    		 10.0
    switching float64

    Time in ps of each switching between the crystal and the springs. Default 50.

    		 50.0
    repeats int32

    Independent free energies of each crystal at each temperature. Default 4.

    		 4
    max_force float64

    Convergence in eV/Å of the relaxation of the fault at each size of the box. Default 1e-4.

    		 0.0001
    max_steps int32

    Largest number of steps of each relaxation. Default 10000.

    		 10000
    seed int32

    Seed of the random numbers, positive. Default 1.

    		 1
    progress callable

    Called as progress(done, total) with the steps run.

    		 None
    cancel CancelToken

    Stops the calculation, which raises mdapy.errors.Cancelled.

    		 None

    Returns:

    Type Description
    FaultFreeEnergyResult

    The free energy of the fault per area, and its error.

    Raises:

    Type Description
    InvalidParameter

    For invalid options, a plane not normal to the axis, a box not periodic in every direction, or if LAMMPS fails.
    MissingProperty

    If the system has no element column.
    Cancelled

    If cancelled.

    Phase diagrams of two elements¶

    binary_phase_diagram ¶

    binary_phase_diagram(phases, temperatures, *, elements=('A', 'B'), points=1001, degree=4)

    The phase diagram of two elements from free energies per atom, at constant pressure: at each temperature the stable phases at each composition lie on the lower convex hull of the free energies of all phases.

    Parameters:

    Name Type Description Default
    phases mapping of str to mapping of float64

    For each phase, its free energies by the fraction of the second element: each a FreeEnergyResult, or a pair of (T,) temperatures in K and (T,) free energies in eV per atom. A phase of one fraction is a compound of that composition. A phase of more is a solution between its lowest and its highest fractions: the free energy minus that of ideal mixing, at each temperature, is a polynomial of the fraction.

    		 required
    temperatures array_like

    (T,) the temperatures of the diagram in K, positive; beyond those of a free energy, it goes on along a straight line.

    		 required
    elements sequence of 2 str

    The elements, for the labels. Default ("A", "B").

    		 ('A', 'B')
    points int32

    Number of fractions from 0 to 1. Default 1001.

    		 1001
    degree int32

    Largest degree of the polynomials. Default 4.

    		 4

    Returns:

    Type Description
    BinaryPhaseDiagram

    The stable phase at each temperature and fraction, and the tie lines.

    Raises:

    Type Description
    InvalidParameter

    For no phases, a fraction out of range, no phase at some fraction, invalid temperatures, points or degree.
