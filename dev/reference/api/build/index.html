    Structure builder¶

    Crystals and alloys¶

    build_crystal ¶

    build_crystal(structure, a, *, c=None, elements='X', orientation=None, repeat=(1, 1, 1))

    A perfect crystal in a periodic box, optionally along chosen crystal directions.

    Parameters:

    Name Type Description Default
    structure str

    One of mdapy.build.STRUCTURES: "sc", "bcc", "fcc", "diamond", "cscl", "rocksalt", "zincblende", "fluorite", "l1_2", "perovskite", "hcp", "wurtzite", "lonsdaleite", "graphite" or "graphene".

    		 required
    a float64

    Lattice constant in Å.

    		 required
    c float64

    Lattice constant c of a hexagonal structure in Å; by default the ideal sqrt(8/3) a, and needed for graphite and graphene.

    		 None
    elements str or sequence of str

    The element of every atom, or of each sublattice of the structure. Default "X".

    		 'X'
    orientation sequence of three directions

    The crystal directions along the three box vectors: [hkl] in the cubic cell, orthogonal; or [uvw] or [hkil] in the hexagonal cell, linearly independent. Default the cell itself.

    		 None
    repeat int32 or sequence of 3 int32

    Number of periods along each box vector, or along all three. Default (1, 1, 1).

    		 (1, 1, 1)

    Returns:

    Type Description
    System

    The crystal, ordered by z, then y, then x.

    random_alloy ¶

    random_alloy(system, fractions, *, seed=None)

    The system with its elements drawn at random in given fractions.

    Parameters:

    Name Type Description Default
    system System

    The sites, for example a crystal from build_crystal.

    		 required
    fractions mapping of str to float64

    Fraction of each element, positive; they are normalized to sum to 1.

    		 required
    seed int64 or Generator

    Seed of the random order; the same seed gives the same alloy.

    		 None

    Returns:

    Type Description
    System

    The system with a new element column. The number of atoms of each element is its fraction of the atoms, rounded so that the counts add up, the largest remainders rounded up.

    sqs_alloy ¶

    sqs_alloy(system, fractions, *, shells=3, weights=None, steps=100000, temperature=1.0, seed=None, progress=None, cancel=None)

    A special quasirandom structure: elements in given fractions on the sites of a perfect lattice, arranged so that the pairs of the nearest shells of neighbors are those of a random alloy.

    Parameters:

    Name Type Description Default
    system System

    The sites, a perfect lattice such as from build_crystal.

    		 required
    fractions mapping of str to float64

    Fraction of each element, positive; normalized to sum to 1, with the counts of random_alloy.

    		 required
    shells int32

    The number of shells of neighbors made random, 1 to 10. Default 3.

    		 3
    weights sequence of float64

    The weight of each shell in the deviation minimized. Default all 1.

    		 None
    steps int64

    Number of swaps of two atoms tried. Default 100000.

    		 100000
    temperature float64

    The starting temperature of the annealing, in units of the typical change of a swap; 0 accepts only improvements. Default 1.

    		 1.0
    seed int64 or Generator

    Seed of the starting alloy and of the swaps.

    		 None

    Returns:

    Type Description
    System

    The system with a new element column.

    Dislocations¶

    insert_dislocation ¶

    insert_dislocation(system, burgers, *, line=2, normal=1, center=None, poisson=1 / 3, elastic=None, orientation=None)

    The system with a straight dislocation along a box axis, its atoms displaced as isotropic or anisotropic elasticity predicts.

    Parameters:

    Name Type Description Default
    system System

    The atoms.

    		 required
    burgers array_like

    (3,) float64 Burgers vector in Å, in the plane of cut: its part along line is the screw part, the rest the edge part.

    		 required
    line int32 or str

    The Cartesian axis along the dislocation line, 0, 1, 2 or x, y, z. Default z.

    		 2
    normal int32 or str

    The Cartesian axis normal to the plane of cut, other than line. Default y.

    		 1
    center array_like

    (3,) float64, a point of the dislocation line in Å. Default the center of the box.

    		 None
    poisson float64

    Poisson's ratio, from -1 to below 0.5, for isotropic elasticity. Default 1/3.

    		 1 / 3
    elastic array_like of float64

    Elastic constants of a cubic crystal for anisotropic elasticity: (C11, C12, C44) or the (6, 6) Voigt matrix, in any unit, in the axes of the cubic cell. Default isotropic elasticity.

    		 None
    orientation array_like

    The crystal directions along x, y and z, orthogonal, with elastic. Default the axes of the cubic cell.

    		 None

    Returns:

    Type Description
    System

    The same atoms, displaced; the box is unchanged.

    edge_dislocation ¶

    edge_dislocation(cell, repeat)

    An edge dislocation between two crystals, with one more period along x below its line than above.

    Parameters:

    Name Type Description Default
    cell System

    An orthogonal periodic cell whose period along x is the Burgers vector, such as fcc along [1-10], [11-2], [111].

    		 required
    repeat tuple of int32

    (nx, ny, nz): above the line nx periods along x, below it nx + 1; ny along y, the line; nz along z in all, at least 2.

    		 required

    Returns:

    Type Description
    System

    The lower crystal compressed and the upper one stretched along x to nx + 1/2 periods, in a box periodic along x and y but not z; the line lies between them, at the middle of x.

    Dislocation dataclass ¶

    Dislocation(structure, orientation, burgers, *, partial=False, core=(0.5, 0.5))

    A straight dislocation in a cubic crystal.

    Attributes:

    Name Type Description
    structure str

    A cubic structure of build_crystal, such as "bcc", "fcc" or "diamond".
    orientation tuple of three directions

    The crystal directions along x, y and z, orthogonal and right-handed: x in the glide plane, y normal to it, z along the line.
    burgers tuple of float64

    The Burgers vector in the axes of the cubic cell, in units of the lattice constant, in the glide plane: the one the dislocation analysis, as OVITO's, finds along +z.
    partial bool

    A single Shockley partial, which bounds a stacking fault on its -x side. Default False.
    core tuple of float64

    Where the line lies: (s, t), s rows of atoms along x from a row of the plane of atoms below it and t of the way to the plane above. Default (0.5, 0.5).

    Polycrystals¶

    build_polycrystal ¶

    build_polycrystal(unit, box, grains, *, orientations=None, min_distance=None, seed=None)

    A polycrystal: each grain the crystal of a unit cell, rotated, filling the Voronoi cell of its seed in a periodic box. With a molecule column in the unit, the molecules stay whole.

    Parameters:

    Name Type Description Default
    unit System

    The crystal of every grain, in a periodic box: a unit cell or any periodic arrangement, such as twin lamellae. Its other columns, such as charges, are kept. With a molecule column, a molecule belongs to the grain that holds its center, the atoms too close are removed by whole molecules, and the topology is kept; a molecule must be shorter than half the box of the unit.

    		 required
    box Box or array_like

    The box of the polycrystal, periodic in every direction: a Box or its lattice vectors. Along an axis no longer than the box of unit, the polycrystal is columnar: every grain spans that axis, its box takes the length of the unit there, and the grains turn about it.

    		 required
    grains int32 or array_like

    Number of grains, with seeds at random positions, or the (G, 3) positions of the seeds in Å.

    		 required
    orientations array_like

    (G, 3, 3) float64 rotation of each grain, taking the axes of unit to those of the box; in a columnar polycrystal rotations about its axis. Uniformly random by default.

    		 None
    min_distance float64

    No two atoms stay closer than this, in Å, with as few removed as possible, as mdapy.neighbor.find_overlapping does: atoms of neighboring grains that come too close, and the copies of atoms on the faces of a cell. Default 0.7 times the nearest distance in unit, between different molecules if there are any.

    		 None
    seed int64 or Generator

    Seed of the random seeds and orientations.

    		 None

    Returns:

    Type Description
    System

    The atoms with a grain column, numbered as the seeds; each seed is a site of the unit in its grain. info["seeds"] holds the (G, 3) positions of the seeds. With molecules, molecule numbers them from 1, and image tells how to put together those the box wraps.

    add_graphene ¶

    add_graphene(polycrystal, *, layers=1, coverage=1.0, clearance=3.0, bond=1.42, spacing=3.35, seed=None)

    Graphene on the grain boundaries of a polycrystal.

    Parameters:

    Name Type Description Default
    polycrystal System

    A polycrystal from build_polycrystal, with the seeds of its grains in info["seeds"] and a grain column.

    		 required
    layers int32

    Number of graphene layers on each boundary, AB stacked and centered on it; where two faces meet, each layer ends where the planes halfway between the faces cross. Default 1.

    		 1
    coverage float64

    Fraction of the area of the boundaries covered, from 0 to 1: whole faces between two grains are covered, in random order, until the fraction is reached. Default 1, every face.

    		 1.0
    clearance float64

    Atoms of the polycrystal closer than this to a carbon atom, in Å, are removed. Default 3, about the distance of graphene from copper.

    		 3.0
    bond float64

    Carbon-carbon bond length of graphene in Å. Default 1.42.

    		 1.42
    spacing float64

    Distance between graphene layers in Å. Default 3.35.

    		 3.35
    seed int64 or Generator

    Seed of the random faces and orientations of the graphene.

    		 None

    Returns:

    Type Description
    System

    The atoms of the polycrystal left and the carbon atoms of the graphene, whose grain is -1; of two carbon atoms of different faces closer than 0.85 bond, where faces meet, the later is left out. The carbon atoms get the other columns of the polycrystal as mdapy.transform.combine gives them: the mass of carbon, a type of their own, ids numbered on, zeros elsewhere. The topology and the info of the polycrystal are kept.

    Raises:

    Type Description
    MissingProperty

    If the polycrystal has no seeds in its info.
    InvalidParameter

    For layers below 1, a coverage outside 0 to 1, or lengths that are not positive.

    Transforming¶

    replicate ¶

    replicate(system, repeat)

    Copies of the system side by side along the lattice vectors.

    Parameters:

    Name Type Description Default
    system System

    The system to copy.

    		 required
    repeat int32 or sequence of 3 int32

    Number of copies along a, b and c, at least 1; more than 1 only along periodic directions.

    		 required

    Returns:

    Type Description
    System

    The copies, one after another with the copy along a changing fastest, in a box with the lattice vectors multiplied by repeat. Ids and molecules (those above 0) of each copy are offset by the largest of the original. With an image column, each atom is placed by its unwrapped position and its image flags are those of the new box, and topology terms are copied within each copy; without one, the copies are translated, and an atom of a term across a periodic boundary is joined to the nearest image of its first atom in the next copy. energy and virial are left out of the info.

    Raises:

    Type Description
    InvalidParameter

    If repeat is not 1 or 3 positive integers, or is above 1 along a non-periodic direction.

    Parameters:

    Name Type Description Default
    system System

    The system to transform.

    		 required
    matrix array_like

    (3, 3) float64 linear part M of the transformation, acting on Cartesian column vectors: a position x goes to M x + t.

    		 required
    translation array_like

    (3,) float64 translation t in Å. Default none.

    		 (0.0, 0.0, 0.0)
    box bool

    Whether the box transforms too: its vectors by M, its origin by M and t. Default True.

    		 True
    vectors sequence of str

    The columns of vectors, of three components, that turn with M without the translation, where the system has them. Default velocities, forces and displacement.

    		 VECTORS
    atoms array_like

    A boolean mask or indices of the atoms that move, with their vectors; the others stay as they are. Default all of them.

    		 None

    Returns:

    Type Description
    System

    The system with the positions, the vectors and, with box, the box transformed; its other columns and its information as they are.

    Raises:

    Type Description
    InvalidParameter

    If the matrix is not (3, 3) of finite numbers, or singular while the box transforms; if the translation is not 3 finite numbers; if atoms is not a mask or indices of the system; or if a column of vectors does not hold three numbers per atom.

    combine ¶

    combine(system, other)

    The atoms of other added after those of system, as OVITO's combine datasets.

    Parameters:

    Name Type Description Default
    system System

    The atoms and the box that are kept.

    		 required
    other System

    The atoms added, at their positions; its box is not used.

    		 required

    Returns:

    Type Description
    System

    The atoms of both in the box of system, with the columns of either: zeros where one has no column (the element X for element), but masses of the elements for mass, and for type the type of an element in the other or new types numbered on. Where either has an id column, the atoms of system keep theirs (or are numbered from 1) and the added atoms are numbered on in their order; molecules of other above 0 are offset by the largest molecule of system. The topology terms of both, those of other moved to its atoms. The info of system, without energy and virial.

    Raises:

    Type Description
    InvalidParameter

    If a column has types in the two that cannot be joined, such as text in one and numbers in the other, or the atoms of one have masses and the others neither masses nor elements.

    Parameters:

    Name Type Description Default
    system System

    The atoms.

    		 required
    cutoff float64 or covalent

    Bonds between atoms closer than this in Å, also across periodic boundaries; or "covalent", between atoms closer than the sum of their covalent radii and 0.45 Å, as mdapy.visualization.covalent_bonds finds them (needs an element column).

    		 required

    Returns:

    Type Description
    System
