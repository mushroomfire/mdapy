    SpatialCorrelation(first, second=None, *, grid_spacing=3.0, window=True, direct=False, cutoff=5.0, bins=50)

    The spatial correlation function of two properties of the atoms, the mean of the first at one place times the second at a distance r from it, by fast Fourier transforms on a grid, as OVITO's spatial correlation function.

    Parameters:

    Name Type Description Default
    first str

    A column of one value per atom, a component such as "velocities.x", or an expression over the columns.

    		 required
    second str

    The other property; default the first, its autocorrelation.

    		 None
    grid_spacing float64

    The approximate size in Å of the cells of the grid. Default 3.

    		 3.0
    window bool

    Weight the atoms by a Hann window along the directions of the box that are not periodic. Default True.

    		 True
    direct bool

    Also sum the correlation over the pairs of neighbors closer than cutoff. Default False.

    		 False
    cutoff float64

    The distance in Å of the direct summation. Default 5.

    		 5.0
    bins int32

    The number of bins of the direct summation. Default 50.

    		 50

    Steinhardt parameters¶

    SteinhardtParameters ¶

    SteinhardtParameters(degrees=(4, 6), *, num_neighbors=None, cutoff=None, voronoi=False, weighted=False, average=False, solid=False, solid_degree=6, bond_threshold=0.7, min_solid_bonds=7)

    Steinhardt bond-orientational order parameters q_l.

    Parameters:

    Name Type Description Default
    degrees sequence of int32

    The degrees l, from 0 to 20. Default (4, 6).

    		 (4, 6)
    num_neighbors int32

    The neighbors of an atom are its num_neighbors nearest; default 12 unless cutoff or voronoi is given.

    		 None
    cutoff float64

    The neighbors of an atom are those closer than cutoff, in Å.

    		 None
    voronoi bool

    The neighbors of an atom are those that share a face of its Voronoi cell. Default False.

    		 False
    weighted bool

    With voronoi, weight each neighbor by the area of its face. Default False.

    		 False
    average bool

    Average the harmonics of each atom with those of its neighbors first (Lechner and Dellago). Default False.

    		 False
    solid bool

    Also tell solid-like atoms from liquid-like ones by their bonds (ten Wolde, Ruiz-Montero and Frenkel). Default False.

    		 False
    solid_degree int32

    With solid, the degree l of the harmonics of the bonds. Default 6.

    		 6
    bond_threshold float64

    With solid, a bond is solid-like when the normalized product of the harmonics of its two atoms exceeds it. Default 0.7.

    		 0.7
    min_solid_bonds int32

    With solid, an atom is solid-like with at least so many solid-like bonds. Default 7.

    		 7

    Parameters:

    Name Type Description Default

    		 False
    polyhedra bool

    Also give the shapes of the cells. Default False.

    		 False
