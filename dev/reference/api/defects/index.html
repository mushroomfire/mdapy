    Defects and deformation¶

    Dislocation analysis¶

    DislocationAnalysis ¶

    DislocationAnalysis(crystal, *, circuit_length=14, stretch=9, perfect_only=False, point_separation=2.5, smoothing=1, mesh_smoothing=8, interface_mesh=False)

    Dislocations of a crystal by the dislocation extraction algorithm (DXA): Burgers circuits on the mesh between the tetrahedra of the atoms where the crystal maps onto the perfect lattice and the rest.

    Parameters:

    Name Type Description Default
    crystal str

    The crystal: fcc, hcp, bcc, cubic_diamond or hexagonal_diamond.

    		 required
    circuit_length int32

    Number of edges of the longest Burgers circuit that finds a line; at least 3. Default 14.

    		 14
    stretch int32

    Number of edges more a circuit may grow to follow a line. Default 9.

    		 9
    perfect_only bool

    Find perfect dislocations only: the stacking faults of fcc and hcp, or of the diamonds, count as defects, without partial dislocations at their edges. Default False.

    		 False
    point_separation float64

    Sparseness of the points along the lines: each point is the mean of a run of the points found, longer where the lines are wider; 0 keeps them all. Default 2.5.

    		 2.5
    smoothing int32

    Number of smoothing steps of the lines. Default 1.

    		 1
    mesh_smoothing int32

    Number of smoothing steps of the defect mesh. Default 8.

    		 8
    interface_mesh bool

    Also give the interface mesh, between the tetrahedra of the good crystal and the rest, on which the circuits run. Default False.

    		 False

    compute ¶

    compute(system, *, progress=None, cancel=None)

    The dislocations of a system.

    Parameters:

    Name Type Description Default
    system System

    The atoms, no two at the same position.

    		 required

    Returns:

    Type Description
    DislocationResult

    The dislocation lines, the structure and crystal cluster of each atom.

    Raises:

    Type Description
    InvalidParameter

    For a box so short along a periodic direction that an atom meets its own periodic image or an edge of the mesh spans half of it: replicate the system first.

    SurfaceMesh ¶

    SurfaceMesh(radius=4.0, smoothing=8, *, regions=False, surface=False)

    The surface of the solid the atoms make, by the alpha-shape method: the space a probe sphere cannot enter is solid.

    Parameters:

    Name Type Description Default
    radius float64

    Radius of the probe sphere in Å: the tetrahedra of the Delaunay tessellation of the atoms whose circumscribed sphere is smaller are solid. Larger than the distance between neighbors, and smaller than the voids looked for. Default 4.

    		 4.0
    smoothing int32

    Number of smoothing steps of the mesh, which round its shape and keep the volumes. Default 8.

    		 8
    regions bool

    Also give the regions of solid and empty space, and the voids among them. Default False.

    		 False
    surface bool

    Also mark the atoms on the surface. Default False.

    		 False

    Chemical species¶

    ChemicalSpecies ¶

    ChemicalSpecies(radii='covalent', *, scale=None, tolerance=None, cutoffs=None)

    Molecules: atoms joined by bonds shorter than their radii allow, and their chemical formulas.

    Two atoms of radii r_i and r_j are bonded when closer than scale * (r_i + r_j) + tolerance, or than the cutoff given for their pair of elements.

    Parameters:

    Name Type Description Default
    radii (covalent, vdw)

    The radius of each element: the covalent radii (Cordero et al. 2008), as Jmol bonds atoms; the van der Waals radii (Alvarez 2013), as VMD and OVITO bond atoms, two hydrogen atoms never bonded unless cutoffs say so; or radii in Å by element. Default "covalent".

    		 "covalent"
    scale float64

    Factor on the sum of the radii. Default 0.6 with van der Waals radii, 1 otherwise.

    		 None
    tolerance float64

    Length added to it, in Å. Default 0.45 with covalent radii, 0 otherwise.

    		 None
    cutoffs dict

    Bond length in Å for pairs of elements (a, b), in either order, instead of the radii; 0 for pairs never bonded.

    		 None

    Atomic strain¶

    AtomicStrain ¶

    AtomicStrain(reference, cutoff, *, affine=False, strain_tensor=False, d2min=False, neighbors=None)

    Atomic strain: the deformation gradient that best maps each atom's neighbor vectors in a reference configuration onto the current ones.

    Parameters:

    Name Type Description Default
    reference System

    The reference configuration, with the same atoms as the systems to compare: matched by the id column where both have one, else in the same order.

    		 required
    cutoff float64

    Neighbors in the reference closer than cutoff, in Å, define the neighbor vectors.

    		 required
    affine bool

    Measure the current vectors in the reference box, which removes the homogeneous deformation of the box. Default False.

    		 False
    strain_tensor bool

    Give the Green-Lagrange strain tensor of each atom. Default False.

    		 False
    d2min bool

    Compute the non-affine squared displacement of each atom. Default False.

    		 False
    neighbors NeighborList

    Neighbors of the reference within at least cutoff, used for every configuration; without, they are found again for each.

    		 None

    ElasticStrain ¶

    ElasticStrain(crystal, a, c=None)
