    Structures and files¶

    Systems¶

    System ¶

    System(positions=None, box=None, *, table=None, elements=None, types=None, info=None, topology=None)

    One atomic configuration: a table of per-atom properties in a box.

    A system never changes. Arrays given to it are copied. Methods named with_*, filter, gather and sort return a new system; columns that are not changed are shared, not copied. The values of each atom are read by name, system["positions"].

    Parameters:

    Name Type Description Default
    positions array_like

    (N, 3) float64 positions in Å. Give either this or table.

    		 None
    box Box or array_like

    Simulation box, or anything Box accepts as lattice vectors. Default: a non-periodic box around the atoms (Box.enclosing).

    		 None
    table DataFrame

    Per-atom table with a positions column of 3 numbers per atom. Give either this or positions.

    		 None
    elements str or sequence of str

    Chemical symbol of every atom, or one symbol for all atoms. Stored in the element column.

    		 None
    types int32 or sequence of int32

    Atom types (from 1) of every atom, or one type for all atoms. Stored in the type column.

    		 None
    info mapping

    Global information such as energy (eV) or timestep.

    		 None
    topology Topology

    Bonds, angles, dihedrals and impropers, with atom indices into the table.

    		 None

    Raises:

    Type Description
    InvalidParameter

    If the inputs are inconsistent: neither or both of positions and table, wrong shapes, non-finite positions, unknown chemical symbols, types below 1, missing values in standard columns, or topology indices beyond the number of atoms.

    table property ¶

    table

    Per-atom properties, one row per atom. A copy that shares the columns: changing it in place does not change the system; use the with_* methods for a changed system.

    box property ¶

    box

    The simulation box.

    info property ¶

    info

    Global information, read-only.

    topology property ¶

    topology

    Bonds, angles, dihedrals and impropers, or None.

    with_table ¶

    with_table(table)

    New system with a different per-atom table, for operations of polars on the whole table that have no method of their own, such as a join.

    Parameters:

    Name Type Description Default
    table DataFrame

    New table with the same number of atoms in the same order, since the topology refers to rows by position. Use sort or gather to reorder atoms and filter to remove them.

    		 required

    Raises:

    Type Description
    InvalidParameter

    If the number of rows differs or the table is invalid.

    New system with added or replaced columns.

    Parameters:

    Name Type Description Default
    *columns Any

    polars expressions or Series, as for DataFrame.with_columns, or results of analyses, whose per-atom values are added.

    		 ()
    **named Any

    Columns by name: polars expressions or Series, NumPy arrays of shape (N,) or (N, ...), or single values for all atoms. A result of an analysis gets the name as a prefix of its columns, which keeps those of two runs with different parameters.

    		 {}

    Returns:

    Type Description

    New system; other columns are shared with this one.

    with_box ¶

    with_box(box, *, scale_positions=False)

    New system in a different box.

    Parameters:

    		 required
    scale_positions bool

    If True, keep the fractional coordinates of the atoms, so that they deform with the box. If False (default), keep the Cartesian positions.

    		 False

    Box ¶

    Box(matrix, origin=(0.0, 0.0, 0.0), pbc=True)

    Simulation box: three lattice vectors, an origin and periodicity.

    Parameters:

    Name Type Description Default
    matrix float64 or array_like

    Lattice vectors in Å. A number gives a cube, three numbers an orthogonal box with these edge lengths, and a (3, 3) array a general box whose rows are the lattice vectors a, b, c.

    		 required
    origin array_like of float64

    Position of the corner of the box in Å. Default (0, 0, 0).

    		 (0.0, 0.0, 0.0)
    pbc bool or sequence of 3 bool

    Whether the box is periodic along a, b and c. Default True.

    		 True

    Raises:

    Type Description
    InvalidParameter

    If the lattice vectors are not finite, have the wrong shape or are linearly dependent, or if origin or pbc are invalid.

    matrix property ¶

    matrix

    (3, 3) lattice vectors in Å, one per row. Read-only.

    origin property ¶

    origin

    (3,) corner of the box in Å. Read-only.

    pbc property ¶

    pbc

    (3,) bool, periodicity along a, b, c. Read-only.

    inverse property ¶

    inverse

    (3, 3) inverse of matrix. Read-only.

    volume property ¶

    volume

    Volume in Å³.

    lengths property ¶

    lengths

    (3,) lengths of a, b, c in Å.

    angles property ¶

    angles

    (3,) angles alpha, beta, gamma in degrees.

    alpha is between b and c, beta between a and c, and gamma between a and b.

    thickness property ¶

    thickness

    (3,) distances in Å between opposite faces of the box.

    Entry i is the distance between the two faces that are not crossed by lattice vector i.

    is_orthogonal property ¶

    is_orthogonal

    Whether the lattice vectors lie along +x, +y and +z.

    to_lammps ¶

    to_lammps()

    This box in LAMMPS restricted triclinic form.

    The box is rotated so that a lies along +x and b in the xy plane with a positive y component. A left-handed set of lattice vectors is first made right-handed by swapping b and c, which describes the same lattice.

    Returns:

    Type Description
    LammpsBox

    Bounds, tilt factors and the rotation to apply to positions and other vectors.

    Topology ¶

    Topology(bonds=None, angles=None, dihedrals=None, impropers=None)

    Bonds, angles, dihedrals and impropers of a molecular system.

    Each kind of term is a polars DataFrame with an atoms column of 0-based atom indices (rows of the system's table), a type column of integer types starting at 1, an optional type_label column, and any further columns.

    Parameters:

    Name Type Description Default
    bonds DataFrame or array_like

    Terms with 2, 3, 4 and 4 atoms. An (M, k) integer array gives atom indices with all types equal to 1. Atom order follows LAMMPS: the central atom of an angle is the second one, dihedral atoms follow the chain, and improper order depends on the improper style.

    		 None
    angles DataFrame or array_like

    Terms with 2, 3, 4 and 4 atoms. An (M, k) integer array gives atom indices with all types equal to 1. Atom order follows LAMMPS: the central atom of an angle is the second one, dihedral atoms follow the chain, and improper order depends on the improper style.

    		 None
    dihedrals DataFrame or array_like

    Terms with 2, 3, 4 and 4 atoms. An (M, k) integer array gives atom indices with all types equal to 1. Atom order follows LAMMPS: the central atom of an angle is the second one, dihedral atoms follow the chain, and improper order depends on the improper style.

    		 None
    impropers DataFrame or array_like

    Terms with 2, 3, 4 and 4 atoms. An (M, k) integer array gives atom indices with all types equal to 1. Atom order follows LAMMPS: the central atom of an angle is the second one, dihedral atoms follow the chain, and improper order depends on the improper style.

    		 None

    Raises:

    Type Description
    InvalidParameter

    If a table has the wrong shape or types, negative indices, a term with a repeated atom, missing values, or a type below 1.

    bonds

    Bonds: atoms holds 2 atom indices.

    angles property ¶

    angles

    dihedrals property ¶

    dihedrals

    Dihedrals: atoms holds 4 atom indices along the chain.

    impropers property ¶

    impropers

    Impropers: atoms holds 4 atom indices.

    tables ¶

    tables()

    max_atom_index ¶

    max_atom_index()

    LammpsBox ¶

    Bases: NamedTuple

    A box in LAMMPS restricted triclinic form.

    Attributes:

    Name Type Description
    lo ndarray

    (3,) float64, (xlo, ylo, zlo) in Å.
    hi ndarray

    (3,) float64, (xhi, yhi, zhi) in Å.
    tilt ndarray

    (3,) float64, tilt factors (xy, xz, yz) in Å.
    rotation ndarray

    (3, 3) float64 rotation matrix. A position or other vector v (row vector) of the original box becomes v @ rotation in the LAMMPS box. It is exactly the identity when the box already has this form.

    read_trajectory ¶

    read_trajectory(path, format=None, *, topology=None, **options)

    Parameters:

    Name Type Description Default

    Trajectory ¶

    Neighbors¶

    NeighborList ¶

    NeighborList(system, cutoff, offsets, j, shifts, distances, num_neighbors=None, areas=None)

    Pairs of atoms within a cutoff, the nearest neighbors of each atom, or the atoms that share a Voronoi face, including periodic images.

    Build one with build. Pairs are grouped by the first atom: the pairs of atom i are offsets[i]:offsets[i + 1]. The vector from atom i to the image of atom j is x[j] - x[i] + shifts @ box.matrix.

    Attributes:

    Name Type Description
    system System

    The system the list was built for.
    cutoff float64

    Every pair is closer than it, in Å.
    num_neighbors int32 or None

    The number of pairs of each atom in a list of nearest neighbors, None otherwise.
    voronoi bool

    Whether the pairs are the atoms that share a Voronoi face.
    offsets ndarray

    (N + 1,) int64.
    j ndarray

    (P,) mdapy.index_dtype, the second atom of each pair.
    shifts ndarray

    (P, 3) int8 periodic image of the second atom.
    distances ndarray

    (P,) float64 distances in Å.
    areas ndarray or None

    (P,) float64 area in Å² of the Voronoi face of each pair in a list of Voronoi neighbors, None otherwise.

    counts property ¶

    (N,) int64 number of pairs of each atom.
